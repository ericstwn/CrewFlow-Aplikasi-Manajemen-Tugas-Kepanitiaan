
# CrewFlow - Aplikasi Manajemen Tugas Kepanitiaan

## Panduan Deploy ke Repository GitHub

Kalo lupa perintah buat ngirim hasil jobdesk ke repo GitHub, pakai perintah ini y guys:

```bash
git add .
git commit -m "Deskripsi progress"
git push
```

Ganti Deskripsi progressnya pakai hasil yg udah dikerjain.

Contoh:

```bash
git add .
git commit -m "Menambahkan fitur login"
git push
```
